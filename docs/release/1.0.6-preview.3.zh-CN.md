# ClipRay 1.0.6 · 预览版 3

本版重点是自动长截图提速、静音桌面录屏卡顿修复，以及自预览版 2 之后的设置和保存体验更新。仍是预览版，不能把本轮长截图验收当成翻译功能已经全面成熟。

## 长截图

自动滚动从一格起步，只按已经确认拼接的位移逐渐增加步长，最多四格，目标每次移动约半个选区。小选区或每格位移较大的来源保持小步。保留采集等待与拼接判据；画面暂时无法可靠对齐时先重采，再继续滚动。手动滚动、暂停、完成和来源窗口保护保留。

同一个 520×600px 选区、3600px 长页面，原版完整采集 15.2 秒，新版 5.9 秒，耗时减少约 61%。最终所有 3600 个物理行的标识逐行核对，无漏行、重行。320ms 平滑滚动样例也完整采到结尾，逐行核对通过；它需要更多等待，不承诺所有页面都同样提速。

样例通过真实原生滚轮、屏幕采集和生产拼接流程运行；另核对来源绑定、手动切换、暂停、暂时低置信画面恢复及完成行为。没有用帧数或图片尺寸单独代替内容完整性。复杂动画、固定浮层或无法提供可靠重叠的页面仍可能暂停或提前结束。

## 录屏和日常体验

- 修复系统无播放时，WASAPI 空音轨拖住视频写入的问题。复用现有 NAudio 的同设备数字静音保活，仅在系统录音期间启用，结束后释放；不访问麦克风、不改变音量。
- 静音、有声转静音、关闭系统录音三种实际录屏核验通过；60fps设置下样例实际约51–55fps，未再出现旧版约一秒的停顿。不是承诺所有机器锁定60fps。
- 录屏帧率、Compact/Balanced/High画质、系统声音和光标可以在设置中选择；既有偏好保留。
- 设置分为常规、保存与复制、录屏、翻译与模型、快捷键、维护与清理、使用帮助。中性深色控件、原彩虹流动效果和系统高对比度降级保留。
- 托盘设置有齿轮入口，最近截取可定位到文件；清理记录补充跳过原因。长截图完成时显示处理状态，Enter可完成。

## 安装、隐私和范围

在原安装目录运行新版安装包即可覆盖升级，无需先卸载。保留设置、API Key、开机启动与清理选择，以及已有成果。安装器请求正常退出；程序忙碌或无法退出时请完成当前操作后再安装，安装器不强杀。

Lite包含基础离线机翻和OCR；Full额外包含Local LMT模型、llama.cpp和相关GPU运行组件。基础机翻与Local LMT在本机处理；只有明确选择云端模型服务时才发送待翻译文字。没有引入上游遥测、更新检查或远程错误上报。

截图翻译和实时翻译仍有漏译、复杂背景排版与识别限制，当前不能宣称日用95%验收通过。Windows Win+V的历史显示和Photoshop粘贴也未在本轮重新验收。另有一条旧后台断言与已存在的轮询次数规则冲突，在原日用版本同样失败；本轮没有修改该断言隐藏失败。源码、构建检查、实际装置验收及用户最终体验分别判断。
