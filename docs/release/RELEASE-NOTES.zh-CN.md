# ClipRay 1.0.6 · 公开预览版

ClipRay 是一个 Windows 截图和原位翻译工具。框选需要看的文字，就能在原来的位置显示译文；也可以固定一块区域，持续翻译里面变化的内容。

这次先把源码和安装包放出来，让大家试着用。截图翻译和实时翻译都还在改，复杂页面上的排版、漏译和小字识别仍然可能出问题。有问题欢迎反馈。

## 下载哪个版本

- **Lite 轻量版**：保留基础离线机翻和 DeepSeek，不包含额外的 Local LMT 大模型及其运行组件。一般先选这个。
- **Full 完全版**：在 Lite 的基础上加入 NiuTrans LMT-60-0.6B Q4_K_M 和 llama.cpp 运行组件，可以在单次区域翻译中选择 Local LMT。

两个版本都默认使用基础离线机翻。DeepSeek 需要自行填写 API Key，调用费用由 DeepSeek 收取。Local LMT 当前不用于实时翻译。

## 最近修了什么

- 实时翻译中，一块文字排版失败时，已经可用的其他译文可以先显示。
- 对字号太小、越界或重叠的译文块做单独处理，减少一个坏块挡住整张画面的情况。
- 调整部分失败重试、缓存和过期结果处理，改善翻译停住后无法继续的问题。
- 修正部分 OCR 文本拼接、数字和界面短词的处理。

这些改动经过了自动检查和一次真实 X 页面测试。复杂动态页面、游戏画面和长时间连续使用还需要更多反馈，不能据此保证所有场景都正常。

## 怎么用

- 截图与区域翻译：`Ctrl+Win+A`，框选后点击翻译。
- 实时翻译：`Ctrl+Win+T` 框选，`Ctrl+Win+Y` 停止。
- 区域录屏：`Ctrl+Win+Z` 开始选区，`F8` 停止。

详细操作见 [使用教程](../ClipRay-使用教程.html)。

## 反馈问题

请说明使用的是 Lite 还是 Full、版本号、翻译路线，以及大致发生了什么。排版问题最好附原图和翻译后的图；实时翻译问题可以补一段短录屏。截图、录屏和日志中如有私密内容，请先遮挡或删去，API Key 不需要提供。
