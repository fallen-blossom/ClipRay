# ClipRay 1.0.6 · 预览版 2

ClipRay 是一个 Windows 截图和原位翻译工具。框选需要看的文字，就能在原来的位置显示译文；也可以固定一块区域，持续翻译里面变化的内容。

这一版支持直接覆盖升级：运行新安装包，在原目录安装即可，不需要先卸载。设置、API Key、开机启动与自动清理选择，以及已有截图、长截图和录屏都会保留。

升级前安装器会请求 ClipRay 正常退出。若旧版本无法自动退出，请完成当前操作，从托盘退出后重试。安装器不强制结束进程；升级期间新版会阻止再次启动。

## 下载哪个版本

- **Lite 轻量版**：保留基础离线机翻和 DeepSeek，不包含额外的 Local LMT 大模型及其运行组件。一般先选这个。
- **Full 完全版**：在 Lite 的基础上加入 NiuTrans LMT-60-0.6B Q4_K_M 和 llama.cpp 运行组件，可以在单次区域翻译中选择 Local LMT。

两个版本都默认使用基础离线机翻。DeepSeek 需要自行填写 API Key，调用费用由 DeepSeek 收取。Local LMT 当前不用于实时翻译。

## 最近修了什么

- 画笔拖动时实时显示，修正方形笔迹造成的毛刺，预览和输出使用圆头线条。
- 新增直线、渐粗箭头、矩形、圆形、椭圆和文字框，共用颜色、撤回和重做。箭头绘制时显示起点提示，确定后提示消失，不进入成果。
- 标注工具收到深色二级菜单；选区尺寸标明 px；长截图底栏为启动、取消、完成。
- 图片剪贴板增加标准 DIB 位图格式，保留 PNG 和文件粘贴。自动复制可在设置中关闭，默认开启。
- 录屏默认采用适合日用的 30 fps 与受控码率，并修复截图、长截图、翻译与退出过程的一批生命周期问题。

Windows 的 Win+V 历史每项上限为 4 MB，不显示视频文件。超大长图仍保留完整文件和剪贴板图片，不为历史显示而缩小原图。

本次改动做了针对性后台检查、隔离安装器夹具验证和独立审查，并构建 Lite 与 Full 安装包。隔离夹具使用测试安装身份与目录，不替代所有真实旧版本、系统和升级失败情形的验收。Win+V 展示、Photoshop 粘贴、多 DPI、动态页面和长时间使用仍需实际使用反馈；预览版不保证所有场景正常。

## 怎么用

- 截图与区域翻译：`Ctrl+Win+A`，框选后点击翻译。
- 实时翻译：`Ctrl+Win+T` 框选，`Ctrl+Win+Y` 停止。
- 区域录屏：`Ctrl+Win+Z` 开始选区，`F8` 停止。

详细操作见 [使用教程](../ClipRay-使用教程.html)。

## 反馈问题

请说明使用的是 Lite 还是 Full、版本号、翻译路线，以及大致发生了什么。排版问题最好附原图和翻译后的图；实时翻译问题可以补一段短录屏。截图、录屏和日志中如有私密内容，请先遮挡或删去，API Key 不需要提供。
