# ClipRay 1.0.6 · 预览版 4

本版更新截图与实时翻译的排版、阅读保底和重复识别速度。它仍是预览版：资源管理器列表中的文字重叠、残字、错位和文件或软件名误译尚未解决，不能视为已达到稳定日用标准。

## 翻译更新

- 对源画面已确认未变化的文字，尽量保持实时译文的位置和字号；画面滚动、文字发生变化或证据不足时重新判断，避免沿用过期译文。
- 改善文字颜色、字号与字重的估计，减少把抗锯齿边缘当成灰字或错误样式的情况；仅在有足够证据时保留局部斜体。复杂背景和特殊字体仍可能还原不准确。
- 原位区域装不下或无法安全覆盖时，保留原画面，并提供“阅读译文”入口。实时翻译隐藏控制条时，可从托盘菜单打开“阅读实时译文”；画面变化后过期内容会移除。
- 对完全相同的文字行复用本次进程中的本地 OCR 识别结果，保留多语言候补识别；首次识别新内容仍需等待，密集页面和云端翻译耗时因机器与服务而异。

样本验证包括真实窗口中的20处文字，以及一处文字更新时其他译文的位置与字号；安装版还用生成的本地样本验证了 OCR 和20处布局。该结果不代表所有页面、游戏或长时间实时翻译都通过验收，也不保证机翻语义准确。

后续用当前安装版处理模拟的深色文件列表时，已复现图标被识别为文字、相邻文件名被合并、文字覆盖图标和原文残笔。这些问题在本预览版中仍存在；该静态样本没有验证滚动时序。

## 已知问题

- 资源管理器等图标紧邻文字的列表中，译文可能与原文、图标或邻近内容重叠，滚动后仍可能出现位置不稳定；部分区域可能只能通过“阅读译文”查看。
- 基础机翻可能错误翻译品牌、软件名和文件名，形似的字母也可能被 OCR 混淆。请以原文为准核对重要名称。
- 小字、渐变或复杂背景、动画和高密度页面仍可能出现漏译、残字或排版问题。连续使用和多显示器尚未充分验证。

## 直接覆盖安装

使用与原安装相同的 Windows 用户，下载 Lite 或 Full 安装包，结束当前截图、长截图或录屏后运行安装程序，选择原安装目录，即可覆盖升级，无需先卸载。安装程序会尝试请求 ClipRay 正常退出；若旧版不支持自动退出或提示程序仍在运行，请从系统托盘退出后重试。

升级会保留现有设置、Windows 凭据中的 API Key、启动和清理偏好，以及已有截图与录屏。不要将其他 Windows 用户或全机安装视为已经验证的迁移路径。完整版改装轻量版时，安装器不会删除旧的完整版模型及运行组件，因此磁盘占用不会自动缩小。

Lite 包含 OCR 和基础离线机翻；Full 额外包含 Local LMT 模型及 llama.cpp。基础机翻与 Local LMT 在本机处理；只有明确选择云端模型服务时才向该服务发送待翻译文字。本次没有新增遥测、自动更新检查或远程错误上报。

同一 Release 提供 Lite、Full、公开源码和 `SHA256SUMS.txt`。公开包不包含私人开发历史、用户截图、录屏、诊断记录或凭据。
