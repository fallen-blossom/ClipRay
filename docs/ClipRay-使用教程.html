今天想用 ClipRay 做什么？

从下面的任务开始。ClipRay 启动后会留在系统托盘；右键托盘图标可以打开设置、开始截取或查看最近保存的成果。

截一张图

  1. 按 Ctrl + Win + A，拖动鼠标框选要保留的画面。
  2. 需要时调整边界，或用工具栏添加标注。
  3. 按 Enter 或点击确认，保存截图。

默认开启“完成后自动复制到剪贴板”。截图和长截图会提供可粘贴的图片；切到聊天框或图片编辑器，按 Ctrl + V 即可粘贴，也可粘贴到文件管理器。

普通框选界面中，连续按两次 Esc 可退出。修改过快捷键时，以设置中的组合键为准。

截取长页面

  1. 先打开要截取的页面，按 Ctrl + Win + A，框选页面的滚动内容区域。
  2. 点击工具栏中的“长截图”，等待程序滚动并收集画面。
  3. 收集到所需内容后，点击“停止并生成”，或按 Esc 停止收集并生成结果。
  4. 在预览中检查拼接位置。结果会先保存，再显示预览；关掉预览不会撤销保存。

框选时尽量避开固定导航栏和侧边栏。动画、图片加载、悬浮元素或页面滚动方式都可能影响拼接；出现重复或缺口时，让页面静止后重新截取，必要时改截较短的范围。

录一段屏幕

  1. 按 Ctrl + Win + Z，框选录制区域。
  2. 按 Enter 或点击确认，开始录制。
  3. 按 F8 停止，等待视频处理完成。

停止后预览可能先显示“处理中”。视频封装完成后才是可用文件；开启“完成后自动复制到剪贴板”时，完成的视频文件会自动放入剪贴板。

需要调整清晰度、帧率、鼠标指针或系统声音时，打开“设置 → 录屏”，修改后点击“保存设置”，用于下一次录制。

提取文字与翻译

复制图片里的文字

  1. 按 Ctrl + Win + A，框选目标文字。
  2. 点击“文字提取”，等待识别结果。
  3. 检查结果，需要时修改文字，再点“一键复制”。

尽量完整框住一段文字，避免边框切断字形。OCR 是文字识别，细小、模糊或复杂排版的文字可能需要手动校对。

翻译一块画面

框选后点击“翻译”。程序先识别文字，再使用“设置 → 翻译与模型”里选择的区域翻译路线。目标语言也在这里修改；工具栏中的翻译按钮支持右键临时切换模型。

持续翻译一个窗口区域

  1. 按 Ctrl + Win + T，在目标应用窗口内框选文字区域。
  2. 保持目标窗口和该区域可见，等待译文更新。
  3. 按 Ctrl + Win + Y 停止。

选区应完整落在同一个应用窗口内。区域翻译与实时翻译分别配置，默认路线都是机翻；实时翻译也可选择 DeepSeek，当前不使用 Local LMT。

复杂滚动页面仍可能漏译或排版错位；视频、游戏和长时间连续使用尚未充分验证。DeepSeek 还会受网络等待影响。若录屏需要录到译文，在设置中开启“在录屏中显示实时译文”，再重新启动实时翻译。

找成果、重新复制

截图、长截图和录屏保存后，都可以从托盘菜单的“最近截取”找回。

  • 找文件：右键托盘图标，打开“最近截取”，点击对应条目，在文件管理器中定位文件。
  • 重新复制：在“最近截取 → 重新复制”子菜单中点击对应条目，再到目标位置按 Ctrl + V。
  • 打开保存目录：进入“设置 → 保存与复制”，打开对应的截图、长截图或录屏目录。

截图和长截图提供图片及文件两种粘贴格式，视频提供文件格式。不同程序对视频文件的接收方式可能不同。

常见问题

粘贴没有反应，或 Win+V 里找不到结果

先从“最近截取”定位文件，确认它已保存完成。截图可用“重新复制”后到聊天框试一次 Ctrl+V，视频可到支持文件粘贴的位置尝试。直接粘贴与 Windows 剪贴板历史需要分别确认；若仍不能粘贴，可以先从保存目录使用文件。

快捷键没有反应

先确认托盘中 ClipRay 正在运行，再打开“设置 → 快捷键”查看组合键和冲突提示。选中快捷键输入框，按下新组合键并保存，再试一次。

实时翻译没有启动，或滚动后漏译

重新框选，确保矩形完整位于同一个应用窗口内。滚动后先让内容停稳，确认目标窗口和选区可见；仍有漏译时，可以停止实时翻译，改用单次区域翻译处理当前内容。

长截图有重复、缺口或拼接不齐

先避开固定导航栏、播放中的动画和正在加载的内容，再缩短截取范围重试。预览适合检查结果，复杂页面仍需逐段核对，不能只看文件生成成功。

录屏周围有 Windows 黄色边框

进入“设置 → 录屏”，打开 Windows 截图边框设置。Windows 允许修改时，按系统提示允许后重启 ClipRay；最终显示方式受 Windows 的捕获权限影响。

找不到 Local LMT，或本地模型尚未就绪

轻量版不含 Local LMT 模型。可以继续使用机翻，或安装完整版后在“翻译与模型”查看模型状态。首次加载本地模型需要等待，也会占用更多磁盘和内存。

自动清理会处理哪些文件

在“设置 → 维护与清理”启用后，Windows 会按设定时间，将超过保留天数且有保存完成记录的 ClipRay 成果移入回收站。旧文件、未完成录屏、恢复数据和其他文件会保留；回收失败会记录并保留原文件。需要长期保存的成果请另存到清理范围之外。

设置在哪里

右键托盘图标打开“设置”，从左侧选择要修改的项目。改好后点击底部“保存设置”；关闭窗口前留意是否还有未保存的修改。

安装版本与卸载

轻量版包含截图、长截图、录屏、OCR、机翻与 DeepSeek 接入，不带 Local LMT 大模型。完整版另含 Local LMT，下载和磁盘占用更大。只想截图或用默认机翻时，轻量版即可。

运行安装程序并启动 ClipRay 后，可以直接从本页前面的任务开始。需要自定义保存位置时，再打开“设置 → 保存与复制”。

如何卸载 ClipRay

打开 Windows 设置 → 应用 → 已安装的应用，找到 ClipRay 并选择卸载。安装版本也可从设置中的“卸载 ClipRay”入口进入卸载程序。已保存成果默认保留；如果在卸载确认页选择回收成果，默认 Outputs 文件夹会移入回收站。

模型与隐私说明

机翻在本机运行，默认用于区域翻译和实时翻译。Local LMT也在本机运行，仅完整版提供，当前用于区域翻译。OCR、截图和录屏均在本机处理。

DeepSeek需要联网和你自己的 API Key。选择这条路线时，识别出的文字与翻译所需的结构化上下文会发送到 DeepSeek 官方 API；不会发送截图像素或视频文件。涉及私密内容时，先确认所选路线。

在 DeepSeek 开放平台创建密钥后，进入“设置 → 翻译与模型”填写并保存。密钥保存在当前 Windows 用户的 Windows Credential Manager，凭据名称为 ClipRay.DeepSeek，不会写入普通设置 JSON。每台电脑、每个 Windows 用户分别保存自己的密钥。

API 的费用和额度以服务方当前规则为准。此教程可离线阅读，但使用 DeepSeek 仍需网络。
