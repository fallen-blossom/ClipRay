离线使用教程 · Windows

从截取画面，到读懂内容

ClipRay 把截图、长截图、录屏、OCR 和翻译放在同一套框选流程里。本页先告诉你该选哪个版本，再按实际任务说明怎么用。

1. 选择安装版本

轻量版 推荐多数用户

包含截图、长截图、录屏、OCR、机翻和 DeepSeek。安装包较小，不包含 Local LMT 大模型。

完整版

在轻量版功能之上加入 Local LMT 本地模型。适合需要完全离线的本地大模型翻译，并且能接受更大的下载和磁盘占用。

拿不准时安装轻量版。机翻属于本地快速兜底，两种安装版本都会保留；以后需要 Local LMT，再改装完整版即可。
  1. 运行安装程序，选择安装目录。
  2. 安装完成后启动 ClipRay。程序会驻留系统托盘，主要功能可从托盘菜单或快捷键打开。
  3. 第一次使用先打开“设置”，确认保存目录、截图格式和翻译路线。

2. 五分钟上手

  1. 按 Ctrl + Win + A，拖动鼠标框选内容。
  2. 在固定工具栏中选择截图、OCR、翻译、长截图或录屏。状态提示可以变化，操作按钮不会跟着提示移动。
  3. 普通截图按 Enter 确认；连续按两次 Esc 退出。
  4. 保存成功后，如果开启“保存后复制文件”，可切到文件管理器按 Ctrl + V 直接粘贴文件。

截图、长截图和录屏都支持这套文件复制方式，也就是保存后可直接 Ctrl+V 粘贴文件。剪贴板中放的是已经保存好的文件，因此关掉预览不会让结果消失。

3. 截图、长截图和录屏

普通截图

框选后可调整边界、做简单标注，再按 Enter 保存。根据设置，图片会写入保存目录，并作为文件放入剪贴板。

长截图

  1. 框选要保留的竖向内容区域，点击“长截图”。区域应覆盖正文的完整宽度，并给滚动内容留出足够高度。
  2. ClipRay 会逐段滚动并拼接。滚动完成等必要信息会显示在状态栏，工具栏位置保持固定。
  3. 按 Enter 完成长截图。程序先保存文件并复制到剪贴板，再展开结果预览。
  4. 预览只用于检查结果；直接关闭预览不会撤销已经完成的保存。
动态页面如果仍在播放动画、加载图片或悬浮栏持续变化，拼接边缘可能不稳定。先让页面静止，再开始长截图。

录屏

框选区域后开始录制，按 F8 停止。停止后会先出现处理中的预览，文件完成封装后自动接入预览；启用“保存后复制文件”时，最终视频文件也会进入剪贴板，可在文件管理器中直接粘贴。

4. OCR 与区域翻译

OCR 只识别框选区域。请让边框贴合目标文字，不要把下一行的一部分留在框内。区域翻译先读取框内文字，再按设置页选择的路线翻译。

路线适合场景特点
机翻英文转简中、无网络环境本地运行，是默认翻译路线，也可用于失败块兜底。
DeepSeek长句、上下文或表达质量优先需要联网和 API Key；只发送识别后的文字与必要上下文。
Local LMT完全离线且希望使用本地模型仅完整版提供；首次加载和翻译会更慢、占用更多磁盘与内存。

设置中的“区域翻译”只影响单次框选翻译。它与实时翻译分别配置，所以可以让区域翻译使用 DeepSeek，同时让实时翻译保持机翻。

5. 实时翻译

实时翻译会持续观察一个应用窗口内的固定区域。开始前必须让框选区域完整落在同一个应用窗口中，不能跨越桌面或其他窗口。

  1. 在设置中选择“实时翻译”路线。默认是机翻；也可改为 DeepSeek。
  2. 按 Ctrl + Win + T，在目标应用窗口内框选较大的正文区域。
  3. 保持目标窗口和内容区域可见。页面滚动后，新进入区域的文字应继续被识别和翻译。
  4. 按 Ctrl + Win + Y 停止。

机翻 默认

当前主要以英文转简中的网页内容进行测试。复杂滚动页面仍可能漏译或排版错位；视频、游戏和长时间连续使用尚未充分验证。

DeepSeek

适合画面变化较慢、希望句意更自然的内容。网络往返会增加延迟，不等同于即时字幕。

Local LMT 当前不用于实时翻译。若录屏需要录到翻译文字，可在设置中开启“在录屏中显示实时译文”；该选项会在下次启动实时翻译时生效。

7. DeepSeek 密钥与隐私

添加 API Key

  1. 登录 DeepSeek 开放平台，创建 API Key。
  2. 在 ClipRay 设置中填入密钥并保存。
  3. 密钥写入当前 Windows 用户的 Windows Credential Manager，固定凭据槽为 ClipRay.DeepSeek，不会写入普通设置 JSON。

打包后的 ClipRay 也使用同一机制。每台电脑、每个 Windows 用户都应保存自己的密钥；安装包不会携带开发者或其他用户的密钥。

哪些内容会离开电脑

  • 截图、录屏、OCR、机翻和 Local LMT 都在本机处理。
  • 选择 DeepSeek 时，会把 OCR 得到的文字和翻译所需的结构化上下文发到 DeepSeek 官方 API；不会上传截图像素或视频文件。
  • 价格和额度可能变化，请查看 DeepSeek 官方价格页。接口使用方法见 官方文档。

8. 故障处理与卸载

框选后提示“实时翻译未启动”

重新框选，并确保整个矩形都在同一个应用窗口内。不要从应用内容区跨到桌面、任务栏或另一个窗口。

滚动后不再翻译

先确认实时翻译仍在运行，并把框选区域扩展到正文完整宽度和足够高度。页面变化太快时先用默认机翻；DeepSeek 更适合更新较慢的内容。

快捷键没有反应

检查托盘中 ClipRay 是否正在运行，再到设置页查看快捷键冲突。修改后保存，按设置页显示的新组合键使用。

找不到 Local LMT

轻量版不含 Local LMT 模型。继续使用机翻或 DeepSeek，或者安装完整版。

如何卸载 ClipRay

打开 Windows 设置 → 应用 → 已安装的应用，找到 ClipRay，选择“卸载 ClipRay”。卸载不会替你删除已经保存的截图、长截图和录屏。
